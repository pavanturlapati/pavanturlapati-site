## The big three

1. **Anthropic released Claude Fable 5.2 and Mythos 5.2**, which it says improve on earlier models in coding and reasoning, at $8 per million input tokens and $40 per million output tokens.
2. **McDonald's connected its loyalty program with Uber**, making Uber Eats its preferred integrated delivery partner in the McDonald's app.
3. **Martin Fowler's site published an article on durable execution for long-horizon agents**, a pattern for recovering from failures during tasks that run for days or weeks.

## AI

### Anthropic releases Claude Fable 5.2 and Mythos 5.2

Anthropic says Claude Fable 5.2 and Mythos 5.2 are the same underlying model, with Fable carrying strong cybersecurity and biology safeguards so it can be offered to all users. Organizations doing beneficial cybersecurity or biomedical work can apply for Mythos access through Anthropic's verification programs. Anthropic says the models generate output up to 30% faster than the 5.1 versions and cost $8 per million input tokens and $40 per million output tokens, with an optional fast mode at $16 and $80. Benchmark figures, the claim of strong results on coding evaluations, and the safety statements are Anthropic's own and have not been independently verified here.

**Why it matters:** the vendor's own advice is to start with a cheaper model for most coding and knowledge tasks and move up only when needed, which suggests model choice is a cost decision as much as a quality one.

*Source: [Hacker News](https://www.anthropic.com/claude-fable-and-mythos-5-2) · 7 min read · Nov 9*

### Hugging Face exec warns cyberattacks could make open source AI less open

Irene Solaiman of Hugging Face said on the Equity podcast that open platforms are attractive targets because they are permissive and hold valuable data. TechCrunch cites an October attack on OpenCode that targeted users' third-party API keys, and Fireworks disclosing that attackers accessed some customers' model weights, datasets and billing information. Solaiman said Hugging Face now rotates administrative access tokens more often and has stricter network controls. A GitHub engineer said npm is tightening publishing requirements and that detecting suspicious behavior is a better investment than limiting functionality.

**Why it matters:** API keys, tokens and data concentrated in AI platforms look like a recurring weak point, which is worth checking in your own tooling.

*Source: [TechCrunch AI](https://techcrunch.com/2026/11/10/cyberattacks-threaten-to-make-open-source-ai-a-little-less-open-hugging-face-exec-warns/) · 4 min read · Nov 10*

### Simon Willison: hide agent-written PR descriptions in details/summary

Simon Willison writes that coding agents produce accurate but long PR descriptions that read like slop. His approach is to write a short human-chosen opener, then place the full agent text inside a collapsed HTML details and summary block, labelled with the model name and often the effort level. He notes GitHub Markdown supports these tags, and lists several of his own pull requests that use the pattern.

**Why it matters:** a short human summary on top of agent output is a cheap way to keep code review readable.

*Source: [Simon Willison](https://simonwillison.net/2026/Nov/9/details-summary/) · 5 min read · Nov 9*

## QSR

### McDonald's connects its loyalty program with Uber

McDonald's and Uber announced that Uber is now connected to the MyMcDonald's Rewards program, and Uber Eats is the preferred integrated delivery fulfillment partner in the McDonald's app. This month, members in certain markets can redeem points on Uber rides as a seasonal activation. Planned future steps include earning points on Uber Eats orders. Restaurant Dive says McDonald's is available through Uber Eats in 30 countries.

**Why it matters:** loyalty is being tied to third-party delivery and ordering channels, which makes integration reliability part of the customer experience.

*Source: [Restaurant Dive](https://www.restaurantdive.com/news/mcdonalds-connects-loyalty-program-with-uber/874177/) · 2 min read · Nov 9*

### McDonald's changes how it collects customer feedback

CEO Chris Kempczinski said on the Q3 2026 earnings call that customers will be able to review their experience inside the McDonald's app, rolling out in the U.S. at the end of Q4. He said it will improve the accuracy and visibility of feedback. The company also said it is expanding a test of ArchIQ, its AI-powered operations platform, across most U.S. restaurants by the end of 2027. Reported results include global comparable sales up 1.5% and U.S. comparable sales down 0.2% in Q3.

**Why it matters:** in-app reviews add a direct feedback signal that quality teams may be able to use alongside other data.

*Source: [Restaurant Dive](https://www.restaurantdive.com/news/mcdonalds-changing-how-it-collects-customer-feedback/873987/) · 3 min read · Nov 9*

### Wendy's CEO details the Dave's Way turnaround plan

Wendy's announced Dave's Way after a 5.7% comparable sales decline in Q3. Plans include rebuilding the menu around core items, a fully refreshed menu in 2027, and making breakfast optional for franchisees. Wendy's also plans stricter brand standards backed by a performance system and combined survey, review and social data to measure satisfaction.

**Why it matters:** the plan ties operations coaching to traffic metrics, an example of measurement driving execution.

## Testing

### Long-horizon agents and durable execution

Kiran Prakash writes that long-horizon agents handle tasks lasting days or weeks, with many exchanges with people and external systems. Failures such as process crashes and network problems can occur along the way. Durable execution records the result of each step that touches the outside world, so after a failure completed steps are skipped and state is rebuilt from the record. The article uses a stock-ordering agent as its running example and also covers retries, code changes under a running task, and text that steers the agent. The listed read time is long, and only part of the text was supplied here.

**Why it matters:** agents that run for weeks will need testing for crashes, duplicate messages and changed conditions, not just single-turn answers.

*Source: [Martin Fowler](https://martinfowler.com/articles/durable-execution-agents.html) · 155 min read · Nov 10*

### Playwright 1.65 adds Bun support and failures-only reporting

Playwright 1.65 can run the test runner under Bun with the --bun flag, with listed limits such as no watch mode. It adds a failures reporter and an onlyFailures option for the HTML, JSON and JUnit reporters. A built-in exclusive lock runs a test only when no other tests are running. Notable changes include sharded runs failing when no tests match across all shards, actions waiting for elements to be not inert, and dropping Node.js 20 testing.

**Why it matters:** several changes, such as the sharding failure and TypeScript class field behavior, could break existing suites, so check release notes before upgrading.

*Source: [Playwright releases](https://github.com/microsoft/playwright/releases/tag/v1.65.0) · 4 min read · Nov 9*
